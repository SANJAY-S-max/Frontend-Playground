# Frontend Playground 🎨

Welcome to my **Frontend Playground**! This is a dedicated repository just for experimenting, tinkering, and learning new frontend techniques. 

## 🌟 What's Inside?
This isn't a structured project, but rather a sandbox for various mini-experiments and practice components:
- **ClickCounter:** Practicing state and event handling.
- **GlowCat:** Fun styling and CSS animation experiments.
- **JS playground:** General JavaScript logic and DOM manipulation practice.
- **Login:** Building basic login UI elements.

## 🛠️ Purpose
I created this repository purely for learning purposes. Whenever I want to try out a new CSS trick, experiment with some raw JavaScript logic, or just play around without breaking a real project, this is where it goes!

## 🚀 Usage
Feel free to browse the folders to see some of my early stage code and learning progress. If you want to run anything, simply open the `.html` files in any web browser!
